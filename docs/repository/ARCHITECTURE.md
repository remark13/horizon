# Устройство Horizon

## Основной путь

1. `/scout` принимает русскоязычный запрос. Внутренние тематические профили
   помогают формулировать поисковые ветви, но не ограничивают интерфейс.
2. API сохраняет план и фоновое задание в PostgreSQL.
3. Worker собирает OpenAlex/arXiv. Версии, идентификаторы источников, даты,
   ограничения покрытия и состояние задания сохраняются отдельно.
4. Нормализация и дедупликация объединяют повторные публикации. Семантические
   представления и тематическое группирование формируют кандидатов.
5. Метрики оценивают рост, новизну, устойчивость и диффузию. Неизвестные значения
   не превращаются в доказанные нули. Рост доли допустим только при сопоставимом
   знаменателе; число найденных работ само по себе не доказывает рост всей темы.
6. Список и карточки показывают объяснение и источники. Публичная подборка
   добавляется отдельно, не становится подтверждённым сигналом автоматически.
7. Пользователь может передать выбранные записи на внутреннюю экспертизу.
   Отсутствие экспертизы не блокирует выдачу. Внешние уведомления не реализованы.

## Оценки

Научные признаки имеют максимальные вклады 40/25/15/10/10: рост, новизна,
устойчивость, независимые группы, объём публикаций. Дополнительный рабочий
балл может учитывать новости до 10, патенты до 10, инвестиционные сообщения
до 5. Общий предел 100. Подробности и ограничения доступны в `/help#scores`.
Научный сохранённый расчёт не переписывается внешними материалами.

«Рынок» означает новостные публикации, а не объём рынка. Гранты и контракты
не приравниваются к инвестиционным сделкам. Динамика найденных новостей
показывается отдельно и не является прогнозом спроса.

## Компоненты

| Слой | Точка входа | Назначение |
| --- | --- | --- |
| Web/API | `saia/api.py`, `saia/scout_web.py` | Запрос, карточки, экспертиза, выгрузка |
| Запуск | `saia/server.py`, `compose.yaml` | Миграции и HTTP-сервис |
| Фоновые задачи | `saia/jobs.py` | Долгие операции вне HTTP-запроса |
| Научный сбор | `saia/discovery.py`, `saia/multi_branch_discovery.py` | Источники и ветви запросов |
| Оценки | `saia/scoring.py` и модули assessment | Вычислимые признаки и объяснения |
| База | `saia/db.py`, `migrations/` | PostgreSQL/pgvector, версия схемы |
| Справка | `saia/help_content.py`, `saia/help_web.py` | Локальные статьи и контекстные ссылки |
| Внешний просмотр | `saia/demo_access.py`, `saia/demo_server.py` | Отдельный защищённый режим чтения |

## Два режима научных данных

Переносимый `compose.yaml` допускает ограниченный живой сбор без зеркала
arXiv. Это облегчённое получение кандидатов с неполным покрытием. Ключ
`SAIA_ALLOW_LIVE_ARXIV` включён только в новом профиле, прежний локальный
режим остаётся прежним.

Большой исследовательский профиль `infra/docker-compose.yml` сохранён для
совместимости и содержит настройки прежней машины. Его нельзя считать
универсальной инструкцией. Для полного корпуса нужны отдельные каталоги,
индексы и модели. Они не являются частью исходного репозитория.

Переключение модели текстового пояснения не меняет автоматически научный
алгоритм, эмбеддинги или оценку. Машинный текст не заменяет первоисточник.
