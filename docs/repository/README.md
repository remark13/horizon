# Horizon

Прототип поиска и анализа кандидатов в слабые научно-технологические сигналы.
Версия 0.4.65, 29 сентября 2026 года. Исследовательский продукт, не production.

Исходный код опубликован участником конкурса для демонстрации и проверки
прототипа. Это не официальный сервис Газпромбанка. Упоминание банка и оформление
прототипа не означают одобрения, поддержки или предоставления сервиса банком.
Публичный доступ к исходникам не означает, что проекту назначена открытая лицензия.

Пользователь задаёт направление на русском языке. Система формирует поисковый
план, собирает публикации, выделяет темы и показывает до 15 кандидатов на
странице. В карточке доступны источники, расчёт оценки и динамика. Экспертиза
необязательна. Публичные подборки отделены меткой происхождения.

## Быстрый запуск

Нужны Docker Engine / Docker Desktop с Compose v2, доступ к реестрам образов
и пакетам. На Linux/macOS откройте терминал в распакованной папке `horizon`:

```sh
cp .env.repository.example .env
# Откройте .env и задайте POSTGRES_PASSWORD: случайные буквы и цифры, минимум 24 символа.
docker compose --env-file .env up --build -d
docker compose ps
```

На Windows создайте копию `.env.repository.example` с именем `.env` через
проводник или `Copy-Item`, затем выполните те же команды Docker.
Не используйте демонстрационный или прежний пароль рабочей базы.

Если установлен Python 3, вместо ручного копирования и задания пароля можно
один раз выполнить `python3 scripts/init_repository_env.py`. Скрипт создаст
`.env` со случайным паролем и не перезапишет существующий файл.

Откройте [рабочее место скаута](http://127.0.0.1:8085/scout),
[публичные подборки](http://127.0.0.1:8085/public-signals) или
[справку](http://127.0.0.1:8085/help).
Первый запуск создаёт отдельную пустую PostgreSQL и применяет миграции.
Рабочая база прежней установки не подключается и не переносится.
Модели загружаются отдельно при первом использовании. Это не занимает
гарантированные 20 минут: лимит ожидания запроса не относится к установке.

```sh
docker compose logs --tail=100 app worker
docker compose stop
docker compose start
```

`stop` сохраняет данные. Не выполняйте `down -v`, если хотите сохранить базу
и результаты. Новая установка не содержит старых поисков или заявок экспертов.

## Что входит

- FastAPI, PostgreSQL/pgvector, фоновый worker, интерфейс и справка.
- Научный поиск OpenAlex/arXiv, нормализация, тематические и временные метрики.
- Коннекторы внешних материалов с явными ограничениями доступа.
- Карточки, графики, публичные подборки, экспертиза, радар, PESTLE и выгрузка.
- Миграции, исходники, конфигурации, переносимые тесты и GitHub Actions.
- Контрольная сумма каждого файла в `MANIFEST.json` исходного архива.

Подключённый коннектор не гарантирует доступность API. Ключи и права для
OpenAlex, EPO OPS, Lens, Event Registry и других каналов настраиваются отдельно.
Скопированные каталоги не означают права на повторную публикацию полных
текстов источников. Список условий: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Что не входит и не обещается

Нет рабочей БД, клиентских таблиц и производного каталога 100 примеров,
пакетов экспертной разметки, PDF, полного arXiv/OpenAlex, весов моделей,
паролей и истории Git. Исследовательские сценарии, требующие этих материалов,
не воспроизводятся одним архивом. История исследований остаётся в исходном
рабочем проекте, а не смешивается с чистым репозиторием.

Переносимый режим использует ограниченный живой сбор без обязательного
локального arXiv. Он не равен покрытию большого локального корпуса. Пустая
выборка или ограничение API не доказывают отсутствие сигнала. Полный анализ
большого корпуса требует отдельной подготовки ресурсов.

Точность детектора, вероятность успеха технологии и соблюдение SLA на любом
оборудовании не доказаны. Балл 0–100 является рабочей оценкой ранжирования.
Отдельная оболочка для внешнего показа доступна только для чтения и с паролем,
это не многопользовательский production и не полноценный публичный поиск.
